# Portable xml2cf

- `xml2cf` — shell launcher (`python3 -m xml2cf`)
- `xml2cf-bin` — Linux one-file binary (PyInstaller)
- `xml2cf.exe` — Windows GUI/CLI: build with Wine or native PyInstaller via `./scripts/build-portable.sh`
- `fixtures/` — dumps for GUI fixture buttons

No args / double-click opens the GUI.
